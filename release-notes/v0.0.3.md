## darts-o-mat v0.0.3

### Playing online with strangers
- **Open lobbies only show while a player is there.** A lobby only appears in the list (and for quick match) while at least one of its players is online. Lobbies whose players have left no longer stick around.
- **Games open to strangers need a time per turn.** A player who walks away is skipped and removed after three turns, so nobody is held up. Because every open lobby now has a time limit, that filter has been removed.
- **The time per turn also counts during the bull-off and the takeout.** If a bull-off dart takes too long, that player drops out of the bull-off. If nobody pulls the darts out in time, the next player is up.
- **The lobby filter fits the game mode.** For X01 it shows start score and check-out. For Around the Clock it shows its own settings (bull at the end, doubles/triples skip).

### Camera (darts-o-cam)
- **Faster detection:** comparing the camera images takes about a third less time.
- **Darts thrown before the takeout no longer count.** A dart that lands after a visit has ended (third dart, bust or won leg) is ignored until the darts are pulled out. Before, it went to the next player.
- **Linux packages:** the .deb and .rpm now install libjpeg-turbo automatically, so darts-o-cam needs considerably less computing power. If you use the .tar.gz, install it yourself (see the [camera README](https://github.com/sj14/darts-o-mat/blob/v0.0.3/cmd/darts-o-cam/README.md)).
- **Linux packages start on every system again.** Packages built on NixOS didn't start elsewhere.
- **Release builds show their version** in the footer and tell you when a newer version is available.
- With `-v`, darts-o-cam logs how long each detection and each report to the server takes.

### Running a server
- **Account management on the admin page:** list and search accounts (newest 50 first, with registration date and last activity), disable accounts (this logs them out) and delete them. To disable or delete an admin, take away the admin role first.
- **Turnstile can be switched off and on** on the admin page when its keys are set. It is on by default, so existing servers keep checking. While it is off, the registration page loads nothing from Cloudflare.
- **A wrong Turnstile secret key now shows up in the log** as a server error. Before, the visitor was simply rejected.
- **Expired sessions are cleaned up** at every login, so the sessions table stops growing.
- **New flag `-no-update-check`** (server and darts-o-cam; Helm: `config.updateCheck: false`) turns off the check for a newer version.

### Updating
- The database is migrated automatically when the server starts (a new index on sessions).
- Open lobbies created before the update that have no time per turn can't be found by strangers until they get one.
