## darts-o-mat (server)

### Games and lobby
- Every game and tournament now begins as a lobby; seats take the account's board, and the lobby asks before the last player leaves.
- A player takes part in one running game at a time.
- Quick match and a filter by strength in the list of open games, which also shows each player's form.
- The last game settings are remembered.
- A game that gets a board after darts were typed in by hand is replayed onto it.
- Warnings from darts-o-cam about a board are shown on the game page.

### Statistics
- The heatmap is drawn as a density, and gets sharper with more darts.
- X01 turns are counted by 60+, 100+, 140+, 170+ and 180.

### Accounts and friends
- Change your password; up to 100 friends and guests.
- Friends show as online, in a game or offline, with an incognito setting.

### Administration
- New admin area: imprint and privacy pages, opening and closing the registration, making other accounts admins.
- The last admin's account can't be deleted.

### Operation
- Several replicas with PostgreSQL: live updates via LISTEN/NOTIFY, changes ordered by an advisory lock, migrations locked.
- Helm chart: optional bundled PostgreSQL, several replicas, a value for every server flag.
- Database migrations for SQLite and PostgreSQL.
- `-pprof` serves Go's profiles on a separate address; `-log-requests` turns on request logging; h2c support.

## darts-o-cam (camera)

### Detection
- Exposure of each camera is matched in software before frames are compared.
- Better detection beside earlier darts: retry without their pixels first, drop finds beside them that aren't the new dart's tip, a tip counts as hidden only right at an earlier dart.
- A black barrel below the seed is followed along the dart's axis.
- Takeout detection votes on all changed pixels, with ties broken by ratios.

### Cameras
- A camera that delivers no frame is left out instead of failing its whole group.
- A hint when a camera delivers much smaller frames than requested.

### Debugging
- The last 5 detections per board are kept in memory as JPEG instead of on disk.
- `-save` writes the frames as PNG, so `darts-o-cam analyze` computes exactly what the detection did.
- `-pprof` for profiles, as on the server.
